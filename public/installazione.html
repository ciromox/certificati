📋 Legge 37/2008

🔌 Gestione Certificazioni Impianti

Applicazione per la gestione delle certificazioni secondo il D.M. 22/01/2008 n. 37

📦 Installazione in Locale

1

Prerequisiti: Installare Node.js (v18 o superiore)

2

Estrarre l'archivio in una cartella a scelta

3

Aprire il terminale nella cartella del progetto ed eseguire:

# Installare le dipendenze
npm install

# Avviare in modalità sviluppo
npm run dev

# Oppure creare la build di produzione
npm run build
# I file saranno nella cartella dist/
4

L'applicazione sarà disponibile all'indirizzo http://localhost:5173

💾 Salvataggio Dati

I dati vengono salvati automaticamente nel browser (localStorage). Utilizzare la funzione "Esporta Dati" per creare un backup JSON. I dati possono essere reimportati in qualsiasi momento con "Importa Dati".

⚠️ Attenzione: I dati sono salvati solo nel browser in uso. Cancellare i dati del browser o cambiare dispositivo comporterà la perdita dei dati se non esportati.

📜 Riferimenti Normativi

D.M. 22 gennaio 2008, n. 37 - Regolamento recante attuazione dell'art. 11-quaterdecies, comma 13, lettera a) della legge n. 248 del 2 dicembre 2005, recante riordino delle disposizioni in materia di attività di installazione degli impianti all'interno degli edifici.

Tipologie impianto: elettrici, idrico-sanitari, gas, riscaldamento, climatizzazione, antincendio, antifurto, ascensori e montacarichi.
