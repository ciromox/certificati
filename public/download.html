🔌 Gestione Certificazioni Impianti

Legge 37/2008 v1.0

📥 Download per Installazione Locale

Scarica i file necessari per installare l'applicazione sul tuo computer.

💡 Suggerimento: La build contiene tutti i file statici necessari. Puoi servirla con qualsiasi web server (Apache, Nginx, Python http.server, ecc.)

⚡ Installazione Rapida

# Metodo 1: Apertura diretta (solo per test)
# Apri il file dist/index.html nel browser

# Metodo 2: Server Python (consigliato)
cd dist
python3 -m http.server 8080
# Apri http://localhost:8080
# Clona o estrai il progetto
cd progetto-certificazioni

# Installa le dipendenze
npm install

# Avvia in modalità sviluppo
npm run dev
# Apri http://localhost:5173

# Build di produzione
npm run build
# Node.js
npx serve dist -p 3000

# PHP
php -S localhost:8080 -t dist

# Python 3
python3 -m http.server 8080 -d dist

# Apache/Nginx: punta DocumentRoot alla cartella dist/

✅ Funzionalità Incluse

  • ✓ Dashboard con statistiche e panoramica
  • ✓ Gestione completa anagrafica clienti
  • ✓ Gestione impianti (8 tipologie: elettrico, idrico, gas, riscaldamento, climatizzazione, antincendio, antifurto, ascensori)
  • ✓ Creazione Dichiarazione di Conformità (DiCo)
  • ✓ Creazione Dichiarazione di Rispondenza (DiRi)
  • ✓ Certificati di verifica e manutenzione
  • ✓ Stampa certificati formato conforme
  • ✓ Configurazione dati tecnico responsabile
  • ✓ Esportazione/Importazione dati JSON
  • ✓ Salvataggio automatico nel browser
  • ✓ Norme CEI di riferimento preconfigurate
  • ✓ Interfaccia responsive (desktop, tablet, mobile)

📜 Riferimento Normativo

D.M. 22 gennaio 2008, n. 37 - Regolamento recante attuazione dell'art. 11-quaterdecies, comma 13, lettera a) della legge n. 248 del 2 dicembre 2005, recante riordino delle disposizioni in materia di attività di installazione degli impianti all'interno degli edifici.
